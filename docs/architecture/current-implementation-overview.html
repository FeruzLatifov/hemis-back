Asosiy texnik qarorlar (so'nggi sessiyalardan)

Qaror 1: Hibernate @Version dan INSERT ON CONFLICT'ga

Muammo

10 parallel POST request bir xil PINFL'lar bilan → 70% ObjectOptimisticLockingFailureException. JPA flow: SELECT employee → UPDATE WITH WHERE version=X — agar version bu vaqtda o'zgargan bo'lsa, exception.

Yechim

JPA save() o'rniga PostgreSQL native INSERT ... ON CONFLICT (pinfl) DO UPDATE. Bir SQL operatsiya, version increment SQL ichida. Custom repository pattern (EmployeeUpsertRepository + EmployeeUpsertRepositoryImpl).

Natija: 0% collision, idempotent, partial unique index WHERE deleted_at IS NULL.

Sabab

Employee sync ko'p row + concurrent. Sinxron => bir HTTP request 30+ sekund => timeout xavfi. Kafka => 202 Accepted darhol, consumer ortda ishlaydi.

HMAC tekshirish kodi

private function verifyHemisSignature() {
    $signature = Yii::$app->request->headers->get('X-Hemis-Signature');
    $timestamp = Yii::$app->request->headers->get('X-Hemis-Timestamp');
    $body = Yii::$app->request->getRawBody();

    // Replay window — 5 daqiqa
    if (abs(time() - intval($timestamp)) > 300) {
        throw new ForbiddenHttpException('Stale timestamp');
    }

    $secret = Yii::$app->params['hemisWebhookSecret'];  // .env'dan
    $expected = hash_hmac('sha256', $timestamp . '.' . $body, $secret);

    if (!hash_equals($expected, $signature)) {           // timing-safe
        throw new ForbiddenHttpException('Invalid signature');
    }
}
